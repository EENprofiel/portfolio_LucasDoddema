# Original HTML Portfolio Archive

This directory contains the original HTML/Tailwind CSS version of Lucas Doddema's portfolio website.

## Files
- `index.html` - Original HTML page
- `src/` - Assets and CSS files
  - `css/` - Tailwind CSS files
  - `images/` - Images and favicon
- `tailwind.config.js` - Tailwind configuration
- `package.json` - Node.js dependencies
- `package-lock.json` - Dependency lock file
- `node_modules/` - Node.js packages

## Purpose
These files are preserved for reference and comparison with the new Flutter implementation. The original design serves as the visual specification for the Flutter migration.

## Technology Stack
- HTML5
- Tailwind CSS 3.4.4
- Iconify for icons
- Inter font family
- Responsive grid layout

## Migration
This version has been migrated to Flutter Web. See `../MIGRATION.md` for details about the migration process and architectural changes.
